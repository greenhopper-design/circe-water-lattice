# 키르케 물격자 (Circe water lattice)

38.5 cm(퓌구시온) 십자 격자는 제자리에 두고, 바람이 지나갈 때 빛과 빈 공간만 물처럼 흐르게 한 건축설계스튜디오 연구.

- `index.html` 처음 화면
- `plan.html` 물격자 평면 12장 — 브라우저에서 실시간 계산, 바람 재생
- `cube.html` 평면을 세운 정육면체 12개 — 미리 계산한 영상, 평면과 나란히 보기
- `lattice.html` 물격자 한 칸 — 장면·바람·빈 공간 방향·물결 조절판
- `engine.js` 공통 계산 (Ken Perlin 개선판 노이즈, 5겹 십자, 빈 공간 흐름)

한 칸 = 10 × 10 m (38.5 cm × 26), 십자 26 × 26개. 열 = 아이올로스 바람 궤도 51 · 74 · 77 · 92.
참고: nD_Rise design studio / RMIT Architecture 002 영상 00:13의 평면 12칸.
